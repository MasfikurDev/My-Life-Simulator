# Roadmap

**Working sequence, not date promises · Reviewed 2026-11-05**

## Milestone 0 — GitHub-first foundation
- [x] Preserve product, gameplay, visual, architecture, and AI collaboration decisions.
- [ ] Build web client and independent simulation boundary.
- [ ] Build minimal Android WebView wrapper.
- [ ] Add focused Actions validation and Pages deployment.
- [ ] Produce installable APK artifact.
- [ ] Verify web updates reach the installed app after fresh launch.

## Milestone 1 — First enjoyable life loop
Character creation and persistent save; readable dashboard; meaningful activities with costs/consequences; deliberate year progression; contextual events and life-history entries; reliable save recovery/migration tests.

## Milestone 2 — Connected systems
Education and career eligibility/progression; income, recurring expenses, savings, debt; family and relationships; events that respond to circumstances; feedback explaining outcomes.

## Milestone 3 — Replayability
More life stages and event variety; personality/trait effects; achievements and optional challenges; balancing based on actual play sessions.

## Later, only when justified
Marriage/children, family trees, property/assets, generational play, cloud backup, online/social features, WASM acceleration after profiling, and monetization after core gameplay validation.

## Scope control
Every milestone needs a playable outcome and acceptance criteria. Avoid parallel implementation of multiple future systems. Prioritize coherence and fun over feature count.
